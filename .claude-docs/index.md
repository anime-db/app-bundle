# Указатель .claude-docs (L1b)

Тонкий слой для агентов. Развёрнутая человеко-документация и аудит — в [../docs/](../docs/).

## Что читать под задачу

| Задача                                               | Файл                                                                                   |
|------------------------------------------------------|----------------------------------------------------------------------------------------|
| Понять устройство бандла, сервисы, события           | [architecture.md](architecture.md) → подробно [../docs/PROJECT.md](../docs/PROJECT.md) |
| Не наступить на грабли при правках                   | [gotchas.md](gotchas.md)                                                               |
| Имя/термин читается неоднозначно (опечатки, нейминг) | [glossary.md](glossary.md)                                                             |
| Кто вызывает код, модель угроз, статус легаси        | [context.md](context.md)                                                               |
| Глубокая техника (планировщик, downloader и т.д.)    | [../docs/TECHNICAL.md](../docs/TECHNICAL.md)                                           |
| Список багов/уязвимостей и фиксы                     | [../docs/BUGS.md](../docs/BUGS.md)                                                     |
| Рекомендации по улучшению/модернизации               | [../docs/RECOMMENDATIONS.md](../docs/RECOMMENDATIONS.md)                               |
| Сводка аудита                                        | [../docs/AUDIT.md](../docs/AUDIT.md)                                                   |

## Разделение слоёв

- **`.claude-docs/`** (L1b) — кратко, для быстрой ориентировки агента: архитектура + подводные камни.
- **`docs/`** — развёрнутый аудит и документация для людей; единый источник деталей.

Точка входа для агента — корневой [../CLAUDE.md](../CLAUDE.md).
