# Глоссарий — anime-db/app-bundle

> Термины и имена, которые легко прочитать неверно: опечатки в коде, исторический нейминг,
> сущности с неочевидными названиями. Только то, что реально сбивает с толку.
> Базовые понятия (Task, Notice, Plugin) описаны в [architecture.md](architecture.md).

## Опечатки, закреплённые в коде (НЕ исправлять вслепую)

| Имя в коде                               | «Правильное» написание | Где                                      | Почему важно                                                                                                                                                                                            |
|------------------------------------------|------------------------|------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `INERVAL_UPDATE`, `INERVAL_NOTIFICATION` | `INTERVAL`             | `Command/ProposeUpdateCommand.php:28,37` | Опечатка в имени константы. `grep INTERVAL` их **не найдёт**. Используются ещё и в `Event/Listener/Project.php` и в миграции `Version20131128101508`. Переименование — breaking change по всем ссылкам. |
| `registr()`, `unregistr()`               | `register/unregister`  | `Service/WidgetsContainer.php:60,81`     | Публичные методы регистрации виджетов названы без `e`. Внешний код вызывает именно эти имена — не «чините» в отрыве.                                                                                    |

`SEE_LATER_INTERVAL` (`Repository/Notice.php:20`) написан правильно — не путать с `INERVAL_*`.

## Похоже-но-разное: сервисы

| Имя                   | Что это на самом деле                                                                                                                                                                                                    |
|-----------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `anime_db.client`     | HTTP-клиент **Guzzle 3** (`Guzzle\Http\Client`). Инжектится в `Downloader` для скачивания файлов.                                                                                                                        |
| `anime_db.api.client` | Клиент **API каталога AnimeDB** (метаданные плагинов: title/description/logo). Инжектится в listener `Package`. Это РАЗНЫЕ сервисы, оба приходят из host-приложения.                                                     |
| `anime_db.filesystem` | Бандловый `Util\Filesystem` со **статическими** методами (home dir, scandir, realpath). DI-определён, но внутренними сервисами бандла **не используется**.                                                               |
| `@filesystem`         | Нативный `Symfony\Component\Filesystem\Filesystem` (подтверждено тайп-хинтом в `CacheClearer::__construct`). Именно его инжектят `CacheClearer`, `Downloader`, listener `Entity`. **Не путать с `anime_db.filesystem`.** |

При правках сервисов помни: `@filesystem ≠ @anime_db.filesystem`. Имя похоже, классы разные.

## Похоже-но-разное: события

| Событие                                      | Кто бросает                                | Назначение                                                             |
|----------------------------------------------|--------------------------------------------|------------------------------------------------------------------------|
| `anime_db.project.installed/updated`         | host-приложение (composer-обёртка проекта) | весь проект установлен/обновлён → перепланирование задач, shmop        |
| `anime_db.package.installed/updated/removed` | host-приложение (на каждый Composer-пакет) | регистрация/удаление `Plugin`, переключение драйвера кэша              |
| `anime_db.widget.get` (`StoreEvents::GET`)   | сам бандл (`WidgetsContainer`)             | «соберите виджеты для места» — внутреннее, не путать с project/package |

`project.*` ≈ «весь проект», `package.*` ≈ «один пакет». Разные слушатели, разная гранулярность.

## Неочевидный нейминг полей и значений

| Имя                  | Что означает                                                                                                                                                           |
|----------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `Task.modify`        | PHP-строка, совместимая со `strtotime`/`DateTime::modify` (`+1 hour`), **а не cron-выражение**. Пусто = одноразовая задача.                                            |
| `Notice.date_start`  | Когда уведомление **начинает** показываться (отложенный показ), не дата создания.                                                                                      |
| `Notice.date_closed` | Когда уведомление авто-закроется (`shown()` ставит `now + lifetime`, по умолчанию 300 сек).                                                                            |
| `Plugin` (ID)        | Первичный ключ — это **имя Composer-пакета** `vendor/name`, а не автоинкремент.                                                                                        |
| `place` (виджеты)    | Строковый «слот» в шаблоне, куда вставляются виджеты-контроллеры (формат `Bundle:Controller:action`).                                                                  |
| `host` (favicon)     | Доменное имя сайта, для которого качается favicon. В маршруте имеет requirement `.+` → допускает `/` и `..` (см. [gotchas.md](gotchas.md)).                            |
| `last_update`        | Параметр в `parameters.yml`, объявлен (`null`), но **не используется** — состояние «пора обновляться» хранится в mtime `composer.json` (см. [context.md](context.md)). |
| `serial_number`      | Параметр в `parameters.yml` (пустая строка) — серийник установки приложения, задаётся host-приложением.                                                                |
| `shmop`              | PHP-расширение разделяемой памяти. Пакет `anime-db/shmop` включает «быстрый» драйвер кэша `cache_time_keeper.driver.multi`.                                            |

## Аббревиатуры и внешние имена

| Термин               | Расшифровка                                                                                               |
|----------------------|-----------------------------------------------------------------------------------------------------------|
| `AnimeDB`            | Настольный менеджер домашней коллекции аниме (это приложение).                                            |
| `app-bundle`         | Этот репозиторий — **ядро/обвязка** (core bundle), не самостоятельное приложение.                         |
| `anime-db/anime-db`  | Host-приложение, в которое встраивается бандл; поставляет манипуляторы composer/parameters и API-клиенты. |
| Gedmo (Translatable) | Doctrine-расширение для переводов сущностей; locale выставляют listener'ы `Request`/`Console`.            |
| DQL `DATETIME()`     | Кастомная DQL-функция (`DQL/Datetime.php`), **SQLite-специфична** — не переносится на MySQL/Postgres.     |
| `cache_time_keeper`  | Родственный бандл, отвечает за HTTP-кэш-заголовки/ETag.                                                   |
